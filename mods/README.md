# Runtime mods

Binary mod JARs are intentionally excluded from Git. The live server currently uses Fabric 0.19.5 for Minecraft 26.2 with Geyser-Fabric, Floodgate-Fabric, ViaFabric, GeyserTPC, Fabric API, and performance/gameplay mods.

Do not install Citizens, Denizen, Sentinel, Geyser-Spigot, Floodgate-Spigot, or OpenAudioMc here. They target Bukkit/Spigot/Paper and are not loadable Fabric mods.

Use `scripts/verify.ps1` to confirm the required cross-play JARs and configuration are present.
